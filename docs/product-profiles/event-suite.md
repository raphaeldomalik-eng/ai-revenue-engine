# Event Suite — active product profile

Phase 1 focuses on event operations: Event Management, Workforce, Production Operations, RSVP, Ticketing, and Event Growth Studio.

Venue is a client type, not a separate Phase 1 product proposition.

The product conceptually supports GROW (Event Growth Studio and relevant Ticketing), MANAGE (Event Management and RSVP), and RUN (Workforce and Production Operations).

Potential differentiation themes are hypotheses, not proven claims: event growth plus operations, connected operations, less fragmented tooling, modular entry/land-and-expand, and optional human/local operator support.
