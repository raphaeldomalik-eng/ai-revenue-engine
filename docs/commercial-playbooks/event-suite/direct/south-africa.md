## Commercial scope

Event Suite Phase 1 is Event Operations: GROW (Event Growth Studio and relevant Ticketing), MANAGE (Event Management and RSVP), and RUN (Workforce and Production Operations). Venue is a client type, especially where it operates multiple events, not a separate product proposition.

## Client and role hypotheses

Initial examples include festival organisers, event promoters, venues running multiple events, event agencies, conference organisers, exhibition/trade-show organisers, corporate event teams, and sports/event organisers. Likely roles include Founder/Owner, Event Director, Event Manager, Operations Director, Head of Events, Production Manager, Marketing/Growth lead, and venue/event-programming leadership. Prioritisation is deferred.
