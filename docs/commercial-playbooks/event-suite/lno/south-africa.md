## Commercial model

An LNO is a channel/business opportunity, not simply a software buyer. The model may include sourcing Event Suite opportunities, introducing/onboarding customers, providing selected local services/support, operating agreed modules/services, and earning attributable commission/revenue.

Primary conversion: business opportunity enquiry/application. A software demo is supporting proof when useful, not the default LNO CTA. LNO human approval remains required.

## Network structure

`Event Suite → Network Operator → Sub-Operator` is the maximum intended structure: one secondary network layer. The currently approved South African operator-pack concept is 20% of qualifying package revenue each portfolio year while originating/servicing, with no automatic commission decay in the current pack.

## Territory boundary

The South African commission concept must not be copied automatically to the UK. Final LNO ICP, operator qualification, approval process, evidence requirements, and UK terms remain deferred.

## Event Suite proposition

The underlying Phase 1 proposition is connected Event Operations across GROW, MANAGE, and RUN. Claims about superiority or uniqueness remain governed hypotheses.
