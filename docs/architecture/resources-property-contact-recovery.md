# Property contact recovery within the existing crawler

Owner-reported UK misses showed operator landing pages displacing the requested
property page, followed by a second-crawl dependency despite contacts already
being observed during website verification. AIRE remains the external acquisition
owner; Nexus classifies/reuses canonical identity; EventSuite owns routing and
publication. The cross-product architecture contract and platform PRD govern.

The existing PUBLIC_CONTACT profile admits actually linked property pages and
property directories, and ranks a matching property above generic group contact
and other-property hire pages. Target-name words are a navigation heuristic,
never a mandatory identity, email-domain or mailbox-name acceptance condition.
An observed group email remains evidence while the crawler follows the linked
property. No guessed URL, cross-host grant or extra request budget is introduced.

The existing signed verification result carries `firstPassAcquisition` inside
its first-party evidence payload only after its existing website assessment
passes. It contains bounded same-crawl source/hash, page/request manifests,
structured identity/contact/venue observations and exact evidence references.
Subjects remain UNKNOWN; this metadata cannot create canonical entities or
publish a listing. Nexus's existing classifier must qualify the venue before
its existing consumer applies observations through EventSuite's Product boundary.
Contacts with concrete source/property/purpose exclusions remain held. Explicit
official-page off-domain enquiry emails remain valid; forms are recorded
separately and do not satisfy the owner's retained email publication requirement.

Tests cover the observed property-link shapes, directory traversal, off-domain
mailto extraction, unchanged request ceilings, unresolved identity withholding,
and cached verification replay without another request. Browser/agent findings
are diagnostic evidence only and are not written into the Production contacts.
Some sites still require governed discovery or expose more redirects than their
signed allowance can cover; those failures remain visible, not fabricated gains.
